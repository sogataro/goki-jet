# あなたは清掃員 / Goki Jet

[English](README.md)

![ゲーム紹介](docs/demo.gif)

プレイURL: https://sogataro.github.io/goki-jet/

PCのChrome・Edge向け、一人称のスーパー清掃ゲーム。ゴキブリ退治と床清掃でお客さんの満足度を守り、0％になるまで続けます。

## 操作
Enterで開始・再開（3秒カウントダウン）。WASD/矢印移動、0.5秒長押しで走行、Spaceジャンプ、マウスで視点、左クリックで使用、右長押しでエイム。Qでモップ/直前武器、Eで攻撃武器切替。Esc停止。

## ルール
退治で20P・満足度＋5、清掃で10P・＋5。発見−10、客への攻撃−15/人。噴射30秒、残量0でも敗北しません。赤い販売機で100P補充、500/1000/1500/3000Pの順番で強化、500Pで爆弾1個。1500Pは射程だけ強化、ショットガンは四角い照準内だけに当たります。

30秒ごと汚れ2か所、6か所以上が15秒続くごと満足度−10。120秒ごとレベルが上がり500P獲得・3匹追加・速度×1.2。客はレベル2・4・6…で1人追加。店は旧レベル3相当（幅・奥行き各1.69倍）で最初から固定。60秒ごと中央に無料ガチャ。200P28％、5倍3匹20％、500P15％、10匹10％、1000P4％、2000P2％、5000P1％、ロケット3発20％。追加個体は再補充なし。満足度90％以上を30秒維持するごと100P。

## ローカル・公開
ビルド不要。`node server.cjs` → http://localhost:8019/ 。テストは`node --test`。静的ファイルをGitHub Pages（main直下）で配信します。共有QRは公開予定URLを指します。

## 保存
言語・感度・アシスト・音量・履歴閲覧・最高Lv/時間をブラウザに保存。途中状態は保存しません。設定から保存データを削除できます。

## Feedback / フィードバック
Use the FB button in the header. Your message, optional contact, app name/version and language are sent to the shared feedback service only when you press Send. Customer and gameplay data are not sent. / ヘッダーのFBから送信できます。送信時のみ本文・任意の連絡先・アプリ名/版/言語を共通受付へ送ります。

## キー配置と拾うアイテム（0.3.0）
設定で各操作を最大2キー／マウスボタンに割り当て、重複時は「すでに使用中」と表示して拒否。初期は従来どおり。自販機・ガチャが未設定なら使用キーを共用。初期配置へ戻すことも可能。キー配置はブラウザ保存。MacBook向けにキーでの使用・エイムと2本指スクロールによる視点操作に対応。

爆弾は500Pで1個追加、所持上限なし。ホイホイは自販機から削除。毎レベル500P。お客は設備と周囲の人を避けた通行可能な通路にランダム出現。

4分ごとに1個、床のランダムな場所へ各25％でアイテム出現。触れると発動：×2は退治/清掃ポイント2倍15秒、おかしは20秒間その場所へ最短の表面経路で誘引（ワープなし）、パワーは15秒間攻撃命中で即退治、どかーんは全生存個体を即退治して報酬加算。時間制効果を上部に残秒表示。同じ効果は持続時間を更新、停止中は進まない。未取得アイテムは残る。
